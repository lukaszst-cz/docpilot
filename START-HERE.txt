DOCPILOT v0.5.1 — WINDOWS
=================================================

Easy start:
    DocPilot.bat

For ordinary users, prefer a GitHub Release build:
    DocPilot-Setup-Windows-x64.exe
or
    DocPilot-Portable-Windows-x64.zip

The release build does not require a separate Python installation.

Core idea:
    Documents + Deadlines + Actions + Archive

Highlights in v0.5.1:
- Review Queue
- local vector search + stronger Local Q&A
- scanned-PDF OCR
- scan auto-rotate / deskew / cleanup
- background deadline notifications
- optional Gmail/Outlook, Notion and Google Calendar connectors
- full archive backup
- PWA

For important documents, review detected data and proposed file changes before applying them.
